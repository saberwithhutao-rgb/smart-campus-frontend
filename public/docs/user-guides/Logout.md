## 🔓 页面简介

退出登录页面是用户点击「退出登录」后看到的过渡页面。系统会自动清理当前用户的登录信息（如Token、用户数据等），并跳转到登录页面。

## 📋 功能说明

### 自动退出流程

1. 用户点击「退出登录」按钮
2. 跳转到退出登录页面
3. 页面显示“正在退出登录...”提示
4. 系统自动执行以下清理操作：
   - 清除本地存储的Token
   - 清除用户信息缓存
   - 重置用户状态
5. 完成后自动跳转到登录页面

### 页面内容

| 元素     | 说明                           |
| -------- | ------------------------------ |
| 标题     | “正在退出登录...”              |
| 提示文字 | “请稍候，正在清理您的登录信息” |
| 加载动画 | 旋转的加载指示器               |

## ⚠️ 注意事项

- 退出登录后需要重新输入账号密码才能使用平台功能
- 如果勾选了「记住我」，退出登录**不会清除**保存的用户名
- 退出登录**不会清除**浏览器中的其他数据（如设置偏好）

## ❓ 常见问题

### ❓ 退出登录后还能自动登录吗？

如果之前勾选了「记住我」，退出登录后再次打开登录页会**自动填充用户名**，但仍需手动输入密码登录。

### ❓ 退出登录卡住怎么办？

如果页面长时间停留在退出状态，请尝试：

1. 手动清除浏览器缓存
2. 刷新页面重新登录
3. 检查网络连接

### ❓ 退出登录和清除缓存的区别？

| 操作     | 说明                                     |
| -------- | ---------------------------------------- |
| 退出登录 | 清除当前用户的登录凭证，需要重新登录     |
| 清除缓存 | 清除浏览器存储的临时数据，不影响登录状态 |

### ❓ 在公共电脑上使用后应该做什么？

建议在公共电脑上使用后**务必点击退出登录**，以保护账号安全。
