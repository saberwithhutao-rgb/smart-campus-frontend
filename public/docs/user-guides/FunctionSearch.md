## 📖 页面简介

功能搜索页面是一个帮助中心入口，用户可以在此搜索平台各项功能的使用说明，快速了解如何使用特定功能。

## 🔍 搜索功能

### 使用步骤

1. 在搜索框中输入功能名称或关键词
2. 按回车键或点击「搜索」按钮
3. 系统会匹配相关的使用指南文档
4. 匹配成功后显示完整的图文使用说明

### 搜索示例

- 输入「登录」→ 显示登录功能使用指南
- 输入「学习计划」→ 显示个人学习计划使用指南
- 输入「图书馆」→ 显示图书馆座位预约使用指南

## 🔥 热门功能

未搜索时，页面会显示「热门功能」标签，点击任意标签可快速搜索：

| 热门功能 | 说明                     |
| -------- | ------------------------ |
| 登录     | 账号密码登录、验证码验证 |
| 注册     | 创建新账号               |
| 学习计划 | 创建和管理学习计划       |
| 复习建议 | AI复习建议生成           |
| 文件上传 | 上传文件供AI分析         |
| 学习任务 | 查看和完成学习任务       |
| 统计     | 学习数据分析             |

## 📄 搜索结果展示

匹配成功后，页面会显示：

- **文档标题**：功能名称
- **文档内容**：渲染后的 Markdown 格式使用指南
  - 标题层级（H1-H3）
  - 列表（有序/无序）
  - 表格
  - 代码块
  - 引用块
  - 强调文本（加粗、斜体）

## 🔗 URL 参数

搜索后，URL 会自动带上 `?q=关键词` 参数，方便分享搜索结果。

例如：`/search?q=登录`

## ❌ 未找到结果

如果没有匹配到相关文档，页面会显示：

- 提示「未找到相关功能」
- 显示搜索的关键词
- 推荐热门功能供用户尝试

## ❓ 常见问题

### ❓ 搜索结果不准确怎么办？

尝试使用更精确的关键词，或从「热门功能」中选择相近的功能进行搜索。

### ❓ 支持模糊搜索吗？

支持。系统会进行关键词包含匹配和标题包含匹配。

### ❓ 搜索框有自动补全吗？

目前不支持自动补全，但热门功能标签可快速选择。

### ❓ 搜索到的文档是最新版吗？

文档与代码版本同步更新，确保内容准确。

### ❓ 可以搜索到所有功能吗？

目前索引了14个核心功能的使用指南，更多功能正在逐步添加。

### ❓ 如何分享搜索结果？

搜索后URL会自动带上 `?q=关键词` 参数，复制链接即可分享给他人。
