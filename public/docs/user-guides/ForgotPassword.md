## 🔑 找回密码步骤

### 第一步：验证身份

1. 在登录页面点击「忘记密码」链接
2. 输入你注册时使用的**邮箱地址**
3. 输入图形验证码（图片上的4位字符，不区分大小写）
4. 如果看不清，可以点击图片或「刷新」按钮更换验证码
5. 点击「发送验证码」按钮

### 第二步：重置密码

1. 查收邮箱，找到6位数字验证码
2. 在输入框中填入验证码（验证码10分钟内有效）
3. 设置新密码（8-20位，必须包含大写字母、小写字母和数字）
4. 再次输入新密码进行确认
5. 点击「重置密码」按钮
6. 系统提示成功后，使用新密码重新登录

## ⏰ 验证码说明

### 图形验证码

- 位于第一步，用于防止恶意请求
- 4位字符，不区分大小写
- 点击图片可刷新

### 邮箱验证码

- 位于第二步，用于验证身份
- 有效期为 **10分钟**
- 6位纯数字
- 60秒内只能获取一次
- 点击「重新发送」可获取新验证码

## ❓ 常见问题

### ❓ 收不到邮箱验证码？

请检查：

- 邮箱地址是否输入正确
- 是否与注册时使用的邮箱一致
- 查看垃圾邮件箱
- 等待60秒后点击「重新发送」

### ❓ 图形验证码总是提示错误？

- 注意区分 0 和 O、1 和 l
- 验证码不区分大小写
- 点击图片刷新一个新的验证码重试

### ❓ 验证码提示过期？

验证码有效期为10分钟，如果超时请点击「重新发送」，使用新的验证码继续操作。

### ❓ 新密码有什么要求？

- 长度：8-20位
- 必须包含：至少1个大写字母（A-Z）
- 必须包含：至少1个小写字母（a-z）
- 必须包含：至少1个数字（0-9）
- 不能包含空格

### ❓ 提示“邮箱不存在”？

说明该邮箱未注册过账号，请检查邮箱是否输入正确，或前往注册页面创建新账号。

## 🔒 安全提醒

- ⚠️ 重置密码后，请使用新密码重新登录
- ⚠️ 不要使用生日、用户名等容易被猜到的密码
- ⚠️ 新密码不要与旧密码相同
- ⚠️ 密码不要告诉他人
