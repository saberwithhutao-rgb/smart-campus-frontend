## 📖 页面简介

校园论坛是一个综合性的校园交流平台，支持发布帖子、评论互动、图片分享等功能。涵盖多个话题分类，满足同学们的日常交流需求。

## 🏷️ 话题分类

论坛提供以下话题标签，点击可筛选对应分类的帖子：

| 话题      | 说明               | 颜色    |
| --------- | ------------------ | ------- |
| #全部     | 显示所有话题的帖子 | 默认    |
| #校园日常 | 分享校园生活点滴   | 🔴 红色 |
| #学习交流 | 学习经验、资料分享 | 🔵 蓝色 |
| #美食推荐 | 校园周边美食探店   | 🟠 橙色 |
| #校园活动 | 活动通知、招募     | 🟢 青色 |
| #求助问答 | 学习/生活问题求助  | 🟣 紫色 |
| #失物招领 | 寻物/招领信息      | 🔴 红色 |
| #表白墙   | 匿名表白、交友     | 🌸 粉色 |
| #二手交易 | 闲置物品买卖       | ⚫ 灰色 |

> 💡 话题栏支持左右滑动查看更多分类，两侧有箭头按钮辅助滚动。

## 📝 浏览帖子

1. 进入论坛页面，默认显示所有帖子
2. 点击话题标签可按分类筛选
3. 帖子卡片显示：
   - 作者头像和昵称
   - 发布时间
   - 所属话题标签
   - 标题和内容
   - 图片（如有）
   - 评论数量
4. 点击评论按钮可展开/收起评论区

## 💬 发表评论

1. 点击帖子右下角的「💬」按钮展开评论区
2. 在输入框中输入评论内容
3. 可选：点击「上传图片」按钮上传评论配图
4. 按回车键或点击「发送」按钮提交评论

## 📤 发布帖子

页面底部有固定的发布栏：

### 第一步：填写信息

1. 选择话题分类（必选）
2. 输入帖子标题（最多100字）
3. 输入帖子内容
4. 可选：点击「上传图片」添加配图

### 第二步：发布

- 点击「发布」按钮
- 系统会自动进行内容审核（敏感词过滤）
- 发布成功后帖子会出现在列表顶部

> 💡 快捷键：在内容输入框中按 `Ctrl + Enter` 可直接发布

## 🖼️ 图片功能

### 上传图片

- 支持多张图片上传
- 点击图片预览可放大查看
- 图片右上角有删除按钮（预览图中）

### 图片预览

- 点击帖子或评论中的图片可全屏预览
- 多图时可左右滑动切换

## 🗑️ 删除功能

### 删除帖子

- 只有自己发布的帖子可以删除
- 点击帖子右下角的「删除」按钮
- 确认后帖子将被永久删除

### 删除评论

- 只有自己发布的评论可以删除
- 在评论右上角点击删除图标
- 确认后评论将被永久删除

## ⚠️ 内容审核

### 发布前审核

- 发布帖子和评论时会自动检测敏感词
- 包含敏感词的内容会被拦截并提示修改

### 违规处理

- 已发布的帖子/评论如被AI检测出违规内容
- 会被自动下架（设为不可见）
- 系统会弹出提示告知用户

## 🔄 加载更多

- 帖子列表支持分页加载
- 滚动到底部点击「加载更多」按钮
- 或继续滚动自动加载（具体取决于实现）

## ❓ 常见问题

### ❓ 为什么我的帖子/评论发布失败？

可能原因：

- 内容包含敏感词汇
- 网络连接问题
- 未选择话题分类

### ❓ 为什么帖子突然不见了？

帖子可能因包含违规内容被系统自动下架。系统会弹出提示告知具体情况。

### ❓ 可以修改已发布的帖子吗？

目前论坛不支持编辑帖子。如需修改，可删除后重新发布。

### ❓ 如何联系发帖人？

目前论坛不提供私信功能，建议在评论区留言交流。二手交易话题可查看帖子中的联系方式。

### ❓ 话题栏滚动不了怎么办？

可以点击话题栏两侧的箭头按钮（←/→）进行滚动。在移动端也可以直接左右滑动。

### ❓ 图片上传有限制吗？

支持常见的图片格式（JPG、PNG等），单次可上传多张图片。具体大小限制取决于服务器配置。
