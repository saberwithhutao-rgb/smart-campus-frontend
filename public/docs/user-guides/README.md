## 💡 使用建议

### 对于新生

建议按顺序阅读：

1. 账号管理（注册、登录、找回密码）
2. 个人中心（查看和编辑资料）
3. 主要功能（图书馆预约、学习计划等）

### 对于老用户

可以直接搜索你需要的功能指南，或收藏常用文档。

### 遇到问题时

1. 先查看对应的使用指南
2. 查看“常见问题”部分
3. 如果仍无法解决，联系学校信息中心

## ❓ 常见问题

### ❓ 为什么我看不到某些功能？

部分功能可能需要登录后才能使用。请先完成登录操作。

### ❓ 文档中的截图和实际页面不一样？

平台功能会持续更新，文档可能存在轻微滞后。如有较大差异，请联系学校信息中心反馈。

### ❓ 如何快速找到我需要的功能指南？

在「功能搜索」页面输入关键词（如“登录”“图书馆”），系统会直接跳转到对应指南。

### ❓ 文档可以下载保存吗？

可以。所有文档都是 Markdown 格式，你可以直接复制内容保存到本地。

### ❓ 文档中的链接打不开怎么办？

请确认文档与其他指南文件在同一目录下。如果是从其他位置打开的，链接可能失效。

## 🔄 更新维护

文档会随平台功能更新同步更新。如有新增功能，相应的使用指南会及时补充。
