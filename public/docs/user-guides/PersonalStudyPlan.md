## 📝 创建学习计划

1. 进入「学习规划」页面（默认显示学习计划）
2. 点击右下角的「➕ 添加新计划」按钮
3. 填写计划信息：
   - **计划名称**（必填）：如“英语四级复习”
   - **计划描述**（选填）：简单描述计划内容
   - **计划类型**：学习 / 复习 / 项目
   - **学科/科目**：数学、英语、计算机等可选
   - **难易程度**：简单 / 中等 / 困难
   - **开始日期**（必填）：计划开始时间
   - **结束日期**（选填）：计划结束时间
4. 点击「创建计划」完成

## ✅ 标记任务完成

1. 在计划列表中找到要完成的计划
2. 点击计划左侧的复选框
3. 确认完成后，计划会标记为「已完成」状态
4. 顶部完成度进度条会自动更新

## ✏️ 编辑计划

1. 找到需要修改的计划
2. 点击计划卡片右侧的「修改」按钮
3. 在弹窗中修改计划信息
4. 点击「保存修改」

**注意：** 已完成的计划不支持修改

## 🗑️ 删除计划

1. 找到需要删除的计划
2. 点击计划卡片右侧的「删除」按钮
3. 确认删除操作
4. 已完成计划删除时会提示关联复习数据也会被清除

## 📊 查看统计

- **完成度**：顶部显示整体完成百分比
- **计划统计**：显示总数、进行中数量、已完成数量
- 点击计划卡片可查看详细内容（跳转至计划详情页）

## 🔗 其他功能

### 智能复习

- 点击侧边栏的「智能复习」可跳转至复习页面
- 有新复习内容时会有红点提示

### 计划详情

- 点击任意计划卡片可进入详情页，查看更详细的信息

## ❓ 常见问题

### ❓ 为什么无法修改已完成的计划？

已完成的计划表示该学习目标已达到，系统限制修改以保持学习记录的准确性。如需调整，可删除后重新创建。

### ❓ 学科/科目有哪些选项？

目前支持：
数学、英语、语文、物理、化学、生物、历史、地理、政治、计算机、编程、算法、数据结构、数据库、前端、后端、移动开发、人工智能、机器学习、深度学习等。

### ❓ 结束日期可以不填吗？

可以。结束日期为选填项，不填写时显示“待定”。

### ❓ 如何查看智能复习？

点击侧边栏的「智能复习」菜单即可进入，该模块会基于你的学习计划生成复习内容。
