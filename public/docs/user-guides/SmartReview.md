## 🧠 什么是智能复习

智能复习基于「艾宾浩斯遗忘曲线」原理,在你快要忘记的时候提醒你复习,让记忆更牢固。系统会自动计算最佳复习时间。

## 📝 添加复习内容

1. 进入「智能复习」页面
2. 点击「添加复习内容」按钮
3. 输入复习标题(如:高等数学第三章公式)
4. 填写详细内容(可以是知识点、公式、笔记等)
5. 选择科目分类(数学、英语、专业课等)
6. 点击「保存」
7. 系统会自动安排第一次复习时间(通常是1天后)

## ✍️ 进行复习

1. 在「今日待复习」列表中查看需要复习的内容
2. 点击任意一条开始复习
3. 仔细阅读内容,尝试回忆
4. 复习完成后,选择掌握程度:
  - 😊 完全掌握 → 下次复习间隔变长
  - 😐 基本掌握 → 正常间隔
  - 😕 不太熟悉 → 缩短间隔,频繁复习
5. 系统会根据你的选择自动安排下次复习时间

## 💡 使用建议

- 每天坚持复习,不要中断
- 如实反馈掌握程度,这样算法才准确
- 重要的知识点可以添加详细备注
- 定期清理已完全掌握的内容
