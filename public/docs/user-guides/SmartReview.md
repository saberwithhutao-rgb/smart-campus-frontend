## 🧠 什么是智能复习

智能复习系统基于**学习计划**自动生成复习任务。当你完成一个学习计划后，系统会根据科学的复习间隔（如1天、3天、7天等）自动安排后续的复习提醒，帮助你巩固知识，避免遗忘。

## 📋 待复习任务

页面顶部展示「待复习任务」列表，包含所有今天需要复习的内容：

| 信息     | 说明                                    |
| -------- | --------------------------------------- |
| 任务标题 | 关联的学习计划名称                      |
| 学科分类 | 计划所属学科（如数学、英语、计算机等）  |
| 复习次数 | 显示当前是第几次复习（如“第 2 次复习”） |
| 任务日期 | 本次复习的计划日期                      |
| 状态     | 显示“待复习”标签                        |

**操作：** 点击任意待复习任务，进入复习详情页进行复习。

## 📚 我的复习计划

页面底部展示「我的复习计划」列表，包含所有已完成的学习计划及其复习进度：

| 信息     | 说明                              |
| -------- | --------------------------------- |
| 计划名称 | 已完成的学习计划标题              |
| 学科分类 | 计划所属学科                      |
| 复习状态 | 进行中 / 未来 / 全部完成 / 无任务 |
| 完成时间 | 计划完成或开始的日期              |
| 状态     | 显示“已完成”标签                  |

**操作：** 点击任意计划卡片，进入复习详情页查看该计划的所有复习任务。

## 🔔 复习提醒

- 当有待复习任务时，侧边栏「智能复习」菜单会显示**红点**提示
- 点击「智能复习」进入页面后，红点自动消失

## 📱 移动端使用

- 点击「打开侧边栏」按钮可以展开左侧菜单
- 任务卡片和计划卡片会自动适配屏幕宽度

## ❓ 常见问题

### ❓ 复习任务是如何生成的？

当你完成一个学习计划后，系统会自动创建复习任务。复习间隔遵循记忆曲线规律，随着复习次数增加，间隔会逐渐延长。

### ❓ 复习状态有哪些含义？

| 状态     | 含义                           |
| -------- | ------------------------------ |
| 进行中   | 还有未完成的复习任务           |
| 未来     | 所有复习任务都在未来日期       |
| 全部完成 | 该计划的所有复习任务已完成     |
| 无任务   | 暂无复习任务（可能刚完成计划） |

### ❓ 如何开始复习？

1. 在「待复习任务」中点击需要复习的计划
2. 进入复习详情页，完成本次复习并选择掌握程度
3. 系统会自动安排下一次复习时间

### ❓ 为什么没有待复习任务？

可能的原因：

- 尚未完成任何学习计划
- 今天的复习任务已全部完成
- 所有计划的复习任务都已结束

### ❓ 如何创建学习计划以使用复习功能？

点击侧边栏的「学习计划」→ 点击右下角「➕ 添加新计划」→ 创建并完成计划后，复习任务会自动生成。
