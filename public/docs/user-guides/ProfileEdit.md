## 📸 更换头像

1. 在头像编辑区域点击「上传新头像」按钮
2. 从电脑中选择一张照片（支持 JPG、PNG 格式，大小不超过 2MB）
3. 头像会立即上传并更新
4. 如果不满意新头像，可以点击「取消」按钮恢复原头像

## ✏️ 可修改的信息

以下信息可以在个人资料页面修改：

| 字段 | 说明                                       |
| ---- | ------------------------------------------ |
| 性别 | 可选择：男 / 女 / 保密                     |
| 学号 | 手动输入                                   |
| 学院 | 可从预设列表中快速选择，也支持手动输入     |
| 专业 | 可从预设列表中快速选择，也支持手动输入     |
| 年级 | 可选择：大一 / 大二 / 大三 / 大四 / 研究生 |

## 🔒 不可修改的信息

以下信息由系统管理，**无法自行修改**：

- **用户名**：注册时设置，不可修改
- **邮箱**：注册时绑定，不可修改

如需修改以上信息，请联系学校信息中心或系统管理员。

## 💾 保存修改

1. 完成信息修改后，点击页面底部的「保存修改」按钮
2. 系统提示保存成功后，会自动返回个人中心

## ❌ 取消修改

- 点击「返回个人中心」按钮可放弃修改并返回
- 点击「取消」按钮也可取消修改

## ❓ 常见问题

### ❓ 头像上传失败？

请检查：

- 文件格式是否为 JPG 或 PNG
- 文件大小是否超过 2MB
- 网络连接是否正常

### ❓ 学院/专业找不到？

- 可以直接手动输入你的学院或专业名称
- 输入时会自动匹配预设选项供快速选择

### ❓ 为什么用户名和邮箱不能修改？

用户名和邮箱是账号的核心标识，用于登录和找回密码，修改需通过管理员审核以确保账号安全。
