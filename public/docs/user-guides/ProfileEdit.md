## 📸 更换头像

1. 在头像区域点击「更换头像」按钮
2. 从电脑中选择一张照片(支持JPG、PNG格式)
3. 拖动裁剪框选择想要的部分
4. 可以放大缩小调整大小
5. 点击「确认裁剪」
6. 头像会立即更新

## ✏️ 修改信息

1. 在对应的输入框中修改信息:昵称、手机号、邮箱、个人简介
2. 修改完成后滚动到页面底部
3. 点击「保存修改」按钮
4. 系统提示保存成功后即完成

## ⚠️ 注意事项

- 学号和姓名不能修改(需联系管理员)
- 头像大小不超过5MB
- 建议使用清晰的正面照片作为头像
- 手机号和邮箱修改后需要验证
