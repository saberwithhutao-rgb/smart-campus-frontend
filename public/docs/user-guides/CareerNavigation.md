## 💬 AI 职业咨询

### 功能介绍

AI职业咨询助手可以回答职业相关问题，提供个性化建议。

### 使用方法

1. 在输入框中输入问题（如“我适合做技术还是产品？”）
2. 按回车键或点击「发送」按钮
3. AI会流式回复，逐字显示回答内容
4. 可以继续追问，AI会记住上下文

### 快捷提问

点击以下示例问题可快速提问：

- “我适合做技术还是产品？”
- “如何准备技术面试？”
- “职业发展路径有哪些选择？”

### 历史记录

- 点击「历史记录」按钮可查看历史会话列表
- 点击任意会话可加载历史聊天记录
- 点击「新对话」按钮开始全新的对话

### 等待提示

AI生成回复时会显示动态提示文案（轮播显示），如“正在连接 AI 服务，请稍候…”等。

## 🎯 热门职业方向

### 分类筛选

职业方向按大类分类，支持筛选：

- 互联网/AI
- 电子/通信/半导体
- 服务业
- 管理类
- 房地产
- 设计
- 制造业
- 教育行业
- 医学
- 药学
- 建筑
- 交通
- 金融

### 职业卡片

每个职业方向卡片包含：
| 信息 | 说明 |
|------|------|
| 图标 | 根据分类显示对应图标 |
| 职业名称 | 如“前端开发工程师” |
| 职业描述 | 简要介绍该职业 |
| 技能标签 | 所需技能（如 JavaScript、React 等） |
| 平均薪资 | 薪资范围（如 15-25K） |

### 查看详情

点击「了解详情」按钮可查看：

- 工作内容
- 发展路径
- 入行要求
- 完整描述

## 📰 职业资讯

### 资讯标签

| 标签         | 说明                   |
| ------------ | ---------------------- |
| 全部资讯     | 查看所有用户发布的资讯 |
| 我发表的资讯 | 仅查看自己发布的资讯   |

### 筛选功能

- 按分类筛选资讯（如“IT行业观察”“求职攻略”等）
- 支持多分类选择

### 资讯卡片

每个资讯卡片包含：

- 标题
- 摘要
- 发布日期
- 分类标签

### 操作功能

- **阅读全文**：点击查看完整内容
- **编辑**（仅自己的资讯）：修改资讯内容
- **删除**（仅自己的资讯）：删除资讯

### 发表资讯

1. 点击「发表资讯」按钮
2. 填写标题、分类、摘要（可选）、正文
3. 点击「发表」提交
4. 审核通过后其他用户可见

### 资讯详情弹窗

- 显示完整内容
- 如果是自己的资讯，可进行编辑或删除

## 📱 移动端适配

- 左侧导航栏默认隐藏，点击右下角菜单按钮展开
- AI聊天区域和历史面板自动适配
- 职业方向和资讯卡片网格自动调整

## ❓ 常见问题

### ❓ AI 回答不准确怎么办？

可以尝试：

- 重新描述问题，提供更多背景信息
- 点击「新对话」重新开始
- 从示例问题中选择类似问题

### ❓ 历史会话会保存多久？

所有历史会话都会保存在服务器，可随时查看。点击「历史记录」即可加载。

### ❓ 如何删除自己发表的资讯？

在「我发表的资讯」标签下，每个资讯卡片都有「删除」按钮，点击确认即可删除。

### ❓ 职业方向薪资数据准确吗？

薪资数据仅供参考，实际薪资受地区、公司、个人能力等因素影响。

### ❓ 资讯发表后多久能通过审核？

资讯发布后会自动进入审核队列，通常在1-2小时内完成审核。
