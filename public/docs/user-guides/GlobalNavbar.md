## 📖 组件简介

`GlobalNavbar` 是智慧校园平台的全局顶部导航栏组件，包含平台 Logo、主导航菜单、子菜单下拉、用户登录状态展示、个人中心下拉菜单等功能。该组件在所有主要页面中固定显示。

## 🧭 导航结构

### 一级菜单

| 菜单项         | 说明             | 子菜单                             |
| -------------- | ---------------- | ---------------------------------- |
| 首页           | 返回平台首页     | 无                                 |
| 个性化学习伴侣 | 学习相关功能入口 | 智能问答、个性化规划、学习管理     |
| 校园生活       | 校园服务入口     | 图书馆预约、体育馆预约、校园论坛   |
| 竞赛管理       | 竞赛信息查看     | 无                                 |
| 职业导航       | 职业发展入口     | AI职业资讯、热门职业方向、职业资讯 |
| 考研支持       | 考研服务入口     | 无                                 |
| 🔍 搜索按钮    | 功能搜索         | 无                                 |

### 子菜单详情

**个性化学习伴侣**

- 智能问答 → `/ai/chat`
- 个性化规划 → `/ai/study`（带红点提醒徽章）
- 学习管理 → `/campus/analysis`

**校园生活**

- 图书馆预约 → `/campus/library-reservation`
- 体育馆预约 → `/campus/sports-reservation`
- 校园论坛 → `/campus/secondhand-market`

**职业导航**

- AI职业资讯 → `/career/position?section=ai`
- 热门职业方向 → `/career/position?section=direction`
- 职业资讯 → `/career/position?section=news`

## 🔔 徽章提醒

- **个性化规划**子菜单带有红点徽章
- 红点通过 `useReviewReminder` 组合式函数控制
- 当有待复习任务时显示红点

## 👤 用户状态

### 未登录状态

- 显示「登录」按钮
- 点击跳转到登录页 `/login`

### 已登录状态

- 显示「个人中心」按钮
- 点击展开下拉菜单：
  - **个人信息** → `/profile`
  - **设置** → `/settings`
  - **退出登录**（需确认，退出后刷新页面）

## 📱 响应式适配

### 桌面端（屏幕宽度 > 768px）

- 水平导航菜单
- 子菜单悬浮显示（鼠标悬停）
- 导航项悬浮有背景色变化

### 移动端（屏幕宽度 ≤ 768px）

- 导航栏高度变为 60px
- 菜单项垂直排列
- 子菜单点击展开（非悬浮）
- 支持侧边栏切换按钮

## ❓ 常见问题

### ❓ 为什么登录后个人中心没有显示？

请检查：

- 确认 `userStore.userState.isLoggedIn` 是否为 `true`
- 确认 localStorage 中是否存在有效 Token
- 刷新页面重试

### ❓ 移动端子菜单无法展开怎么办？

移动端子菜单采用点击展开机制，点击父菜单即可展开/收起。如果仍无法展开，请检查屏幕宽度检测是否正常（≤ 768px）。

### ❓ 红点徽章一直显示怎么办？

红点表示有待复习任务。完成所有待复习任务后，红点会自动消失。如需手动清除，可进入「个性化规划」页面查看。

### ❓ 退出登录后页面没有刷新？

退出登录后组件会调用 `window.location.reload()` 刷新页面。如果未刷新，请检查浏览器是否禁用了 JavaScript 或存在缓存问题。

### ❓ Logo 图片不显示？

请确认图片路径 `/src/img/logo_xr.png` 是否存在。如路径不同，请修改组件中的 `src` 属性。

### ❓ 子菜单在桌面端不显示？

桌面端子菜单通过鼠标悬停触发。如果悬停不显示，请检查是否有 CSS 样式冲突或 `isMobile` 状态误判。

### ❓ 如何修改导航菜单项？

在组件的 template 中修改对应的菜单项和 `@click` 跳转方法，同时更新路由配置。

---

> 💬 **使用建议**：该组件应在 `App.vue` 或根布局中全局引入，确保所有页面都能显示导航栏。
