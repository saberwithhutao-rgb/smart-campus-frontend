## 📖 页面简介

复习详情页用于查看某个复习任务的详细信息，包括复习阶段、AI生成的复习建议内容，并支持完成复习和查看历史复习版本。从「智能复习」页面点击待复习任务或复习计划卡片进入。

## 📋 复习任务信息

页面顶部展示当前复习任务的基本信息：

| 信息         | 说明                                        |
| ------------ | ------------------------------------------- |
| 任务标题     | 关联的学习计划名称                          |
| 复习阶段     | 第 X 次复习（如“第一次复习”“第二次复习”等） |
| 生成时间     | 该复习任务的创建时间                        |
| 复习阶段说明 | 基于记忆曲线的阶段描述                      |
| 状态标签     | 待复习 / 距离复习还有 X 天 / 已完成         |

### 状态说明

| 状态              | 含义                            | 标签颜色 |
| ----------------- | ------------------------------- | -------- |
| 待复习            | 任务日期 ≤ 今天，需要立即复习   | 黄色     |
| 距离复习还有 X 天 | 任务日期 > 今天，还未到复习时间 | 蓝色     |
| 已完成            | 复习任务已标记完成              | 绿色     |

## 🤖 AI生成复习建议

点击「AI生成复习建议」按钮，系统会根据以下信息自动生成个性化的复习内容：

- 学习计划标题
- 当前复习阶段
- 历史复习记录

**生成过程：**

1. 点击按钮后，显示「AI 正在为你生成复习建议」卡片
2. 卡片显示已等待时间（秒数）和进度条
3. 生成完成后显示总耗时，并弹出成功提示
4. 生成的复习建议以 Markdown 格式展示在下方卡片中

> 💡 **提示**：复习建议越详细，生成时间可能越长，请耐心等待。生成中的任务刷新页面后会恢复等待状态。

## ✅ 完成复习

当复习任务状态为「待复习」时，可以点击「复习完成」按钮：

1. 点击按钮会弹出确认对话框
2. 确认后，系统标记本次复习为「已完成」
3. **自动生成下一次复习任务**（基于记忆曲线间隔）
4. 完成后自动返回智能复习列表页

**注意：**

- 只有任务日期 ≤ 今天的任务才能完成
- 未来的任务（距离复习还有 X 天）无法完成
- 已完成的复习任务无法再次完成

## 📜 查看历史复习建议

点击「查看历史复习建议」按钮，弹出历史版本弹窗：

**功能特点：**

- 按复习阶段分组显示（第1次、第2次等）
- 每个阶段显示所有历史版本，按版本号倒序排列
- 当前使用的版本有「当前使用」标记
- 点击任意历史版本可查看完整内容
- 支持按阶段筛选（下拉选择）

**筛选功能：**

- 选择「全部阶段」显示所有阶段
- 选择特定阶段只显示该阶段的复习建议
- 每个选项旁边显示该阶段的版本数量

## 📝 复习内容展示

生成的复习建议以富文本格式展示，支持：

- **标题**（H1-H6）
- **加粗**、_斜体_
- 列表（有序/无序）
- 代码块（带语法高亮）
- 链接
- 引用
- 表格

## 🔙 返回操作

点击左上角的「返回」按钮可返回上一页（智能复习列表）。

## 📱 移动端使用

- 历史弹窗和详情弹窗会自动适配屏幕宽度
- 筛选区域在移动端会垂直排列

## ❓ 常见问题

### ❓ 什么是复习阶段？

复习阶段表示这是该学习计划的第几次复习。系统基于记忆曲线自动安排复习间隔，随着阶段增加，间隔会逐渐延长。

### ❓ 如何知道今天有哪些复习任务？

进入「智能复习」页面，顶部「待复习任务」列表会显示所有今天需要复习的任务。

### ❓ 为什么按钮显示“暂无进行中的任务”？

可能的原因：

- 当前复习任务日期 > 今天（未来任务）
- 复习任务已完成
- 当前没有待复习任务

### ❓ 完成复习后会发生什么？

系统会：

1. 标记本次复习为已完成
2. 根据记忆曲线计算下一次复习时间
3. 自动创建下一次复习任务
4. 返回列表页，可以看到新的待复习任务

### ❓ 历史复习建议会保存多久？

所有生成的复习建议版本都会永久保存在服务器，可以在「历史复习建议」中随时查看。

### ❓ 可以重复生成复习建议吗？

可以。每次点击「AI生成复习建议」都会生成新版本，旧版本会自动保存到历史记录中。
