## 📖 页面简介

学习计划详情页用于查看某个学习计划的完整信息，并利用AI生成专属的学习方案。该页面从「个人学习计划」页面点击计划卡片进入。

## 📋 查看计划信息

页面顶部展示当前学习计划的详细信息：

| 字段     | 说明                                           |
| -------- | ---------------------------------------------- |
| 计划名称 | 学习计划的标题                                 |
| 计划描述 | 创建时填写的详细描述                           |
| 计划类型 | 学习计划 / 复习计划 / 项目计划                 |
| 学科     | 所属学科（如数学、英语、计算机等）             |
| 难度     | 简单 / 中等 / 困难                             |
| 时间范围 | 开始日期 至 结束日期（无结束日期显示“无限期”） |

## 🤖 生成专属学习计划

点击「生成专属学习计划」按钮，AI会根据以下信息自动生成个性化学习方案：

- 计划标题和描述
- 学科类型
- 计划时长（根据开始/结束日期自动计算天数）
- 难度等级

**生成过程：**

1. 点击按钮后，会显示「AI 正在为你生成学习计划」卡片
2. 卡片会显示已等待时间（秒数）和进度条
3. 生成完成后会显示总耗时，并弹出成功提示
4. 生成的计划内容会以 Markdown 格式展示在下方

> 💡 **提示**：计划越详细，生成时间可能越长，请耐心等待。生成中的计划刷新页面后会恢复等待状态。

## 📜 查看往期计划

1. 点击「查看往期计划」按钮
2. 弹出历史计划弹窗，按时间倒序展示所有生成过的计划
3. 每个历史计划显示：计划ID、生成时间、时长、难度、内容预览
4. 点击任意历史计划卡片可查看完整内容
5. 点击「← 返回列表」可回到历史列表

## 📝 计划内容展示

生成的计划以富文本格式展示，支持：

- **标题**（H1-H6）
- **加粗**、_斜体_
- 列表（有序/无序）
- 代码块（带语法高亮）
- 链接
- 引用

## 🔙 返回操作

点击左上角的「返回」按钮可返回上一页（个人学习计划列表）。

## ❓ 常见问题

### ❓ 为什么生成计划需要等待？

AI 生成学习计划需要根据你的计划信息进行深度分析，生成详细的阶段性学习安排。生成时间通常为几秒到几十秒不等。

### ❓ 生成过程中可以关闭页面吗？

不建议关闭。如果意外关闭，重新进入该计划详情页后，系统会自动恢复生成状态并继续等待。

### ❓ 历史计划会保存多久？

所有生成的历史计划都会永久保存在服务器，可以在「往期计划」中随时查看。

### ❓ 同一个计划可以多次生成吗？

可以。每次点击「生成专属学习计划」都会生成新的方案，历史记录中会保留所有生成过的版本。

### ❓ 计划没有结束日期怎么办？

如果创建计划时未设置结束日期，AI 生成时会使用「无限期」作为时长，生成的学习方案会更灵活。
