## 📖 页面简介

考研支持页面为考研学生提供一站式服务，包括考试倒计时、院校选择与收藏、学习进度跟踪等功能，帮助用户高效备考。

## 📊 顶部统计卡片

### 考试倒计时卡片

显示最近的考研/考试信息：

- 考试名称（如“全国硕士研究生招生考试”）
- 考试日期范围
- 实时倒计时（天、时、分、秒）

> 💡 倒计时每秒自动更新，考试结束后不再显示。

### 院校选择卡片

- 显示已收藏的院校数量
- 点击「查看收藏」按钮可查看收藏列表弹窗

### 学习进度卡片

显示当前学习进度：

- 总体完成百分比（进度条可视化）
- 各科目/知识点的完成进度
- 支持添加、编辑、删除进度项

## 🏫 院校选择

### 搜索功能

- 在搜索框中输入院校名称关键词
- 按回车键或点击「搜索」按钮进行筛选
- 支持模糊匹配（院校全称和简称）

### 院校列表

每个院校卡片包含：

| 信息       | 说明                        |
| ---------- | --------------------------- |
| 院校名称   | 全称 + 简称                 |
| 标签       | 985 / 211 / 双一流 / 所在地 |
| 院校代码   | 官方招生代码                |
| 院校类型   | 综合类/理工类/师范类等      |
| 培养层次   | 博士点 / 硕士点             |
| 自定义标签 | 院校特色标签                |

### 操作按钮

| 按钮        | 说明                                   |
| ----------- | -------------------------------------- |
| 收藏/已收藏 | 切换收藏状态，收藏后可在收藏列表中查看 |
| 官网        | 跳转至院校官方网站                     |

## ⭐ 收藏院校

### 添加收藏

- 点击院校卡片上的「收藏」按钮
- 收藏成功后按钮变为「已收藏」

### 查看收藏

- 点击顶部统计卡片的「查看收藏」按钮
- 弹出收藏列表弹窗，显示所有已收藏院校

### 取消收藏

- 在收藏列表弹窗中点击「取消收藏」按钮
- 或在院校卡片上点击「已收藏」按钮

## 📈 学习进度管理

### 查看进度

- 总体进度以进度条形式展示
- 各科目/知识点显示名称和完成百分比

### 添加进度项

1. 点击「+ 添加科目/知识点」按钮
2. 输入科目/知识点名称
3. 设置完成百分比（0-100）
4. 点击「添加」保存

### 编辑进度项

1. 点击科目旁的「编辑」按钮
2. 修改名称或百分比
3. 点击「保存」确认修改

### 删除进度项

- 点击科目旁的「删除」按钮
- 确认后该进度项将被移除

## ❓ 常见问题

### ❓ 倒计时不准确怎么办？

倒计时基于考试的开始日期计算，每秒自动更新。如果发现日期有误，请联系管理员更新考试信息。

### ❓ 收藏的院校会同步到其他设备吗？

会。收藏列表与账号绑定，登录同一账号可在不同设备上查看。

### ❓ 学习进度数据会丢失吗？

学习进度保存在服务器端，不会因清除浏览器缓存而丢失。

### ❓ 如何修改已添加的学习进度？

点击科目旁的「编辑」按钮即可修改名称和百分比。

### ❓ 院校搜索支持哪些字段？

支持按院校全称和简称进行模糊搜索。

### ❓ 为什么有些院校没有“官网”按钮？

只有系统中录入了官方网站地址的院校才会显示「官网」按钮。
