## 📖 页面简介

竞赛管理系统用于查看各类学科竞赛信息，支持按类型、状态、级别筛选和关键词搜索。同时提供职业导航和考研支持的快速入口。

## 🧭 左侧导航栏

| 菜单        | 说明                   | 跳转页面           |
| ----------- | ---------------------- | ------------------ |
| 🏆 竞赛管理 | 当前页面，查看竞赛列表 | 当前页             |
| 🎯 职业导航 | 职业发展相关服务       | `/career/position` |
| 📖 考研支持 | 考研相关信息支持       | `/career/pee`      |

## 🏆 浏览竞赛

### 竞赛列表

进入页面后，默认显示所有竞赛。每个竞赛卡片包含：

| 信息     | 说明                                   |
| -------- | -------------------------------------- |
| 竞赛名称 | 竞赛的完整名称                         |
| 竞赛描述 | 简要介绍竞赛内容                       |
| 时间     | 竞赛举办时间                           |
| 时长     | 竞赛持续时间                           |
| 地点     | 竞赛举办地点                           |
| 级别     | 国家级 / 省级 / 校级                   |
| 标签     | 竞赛类型标签（如程序设计、数学建模等） |
| 状态标签 | 进行中 / 即将开始 / 已结束             |

### 筛选功能

页面提供多种筛选条件：

| 筛选项   | 选项                                         |
| -------- | -------------------------------------------- |
| 竞赛类型 | 全部 / 程序设计 / 数学建模 / 创意设计 / 其他 |
| 状态     | 全部 / 进行中 / 即将开始 / 已结束            |
| 级别     | 全部 / 国家级 / 省级 / 校级                  |

### 搜索功能

- 在搜索框中输入竞赛名称关键词
- 按回车键或点击 🔍 按钮进行搜索
- 支持模糊匹配

## 📝 报名参赛

### 进行中的竞赛

1. 找到状态为「进行中」的竞赛
2. 点击「前往官网」按钮
3. 跳转到竞赛官方网站进行报名

### 即将开始的竞赛

1. 找到状态为「即将开始」的竞赛
2. 点击「立即报名」按钮（功能与「前往官网」相同）
3. 跳转至官方网站了解详情

### 已结束的竞赛

- 状态为「已结束」的竞赛按钮会显示「已结束」并禁用
- 点击「查看结果」可查看竞赛结果（跳转至详情页）

## 📋 查看详情

点击「查看详情」按钮可进入竞赛详情页，查看：

- 完整的竞赛介绍
- 比赛规则和要求
- 奖项设置
- 赛程安排

> 💡 已结束的竞赛「查看详情」按钮会变为「查看结果」

## 🎨 状态标签颜色

| 状态     | 颜色    | 说明                               |
| -------- | ------- | ---------------------------------- |
| 进行中   | 🟢 绿色 | 正在进行的竞赛，可点击「前往官网」 |

## ❓ 常见问题

### ❓ 为什么点击报名后跳转到外部网站？

竞赛报名统一由各竞赛主办方管理，平台仅提供信息展示和官方链接跳转。请根据官网指引完成报名流程。

### ❓ 如何查看已报名的竞赛？

目前平台不存储用户的竞赛报名记录。如需查看，请登录各竞赛官网查询。

### ❓ 竞赛信息多久更新一次？

竞赛信息会定期同步更新。如发现信息有误，请联系学校信息中心反馈。

### ❓ 筛选和搜索可以组合使用吗？

可以。筛选条件（类型、状态、级别）和搜索关键词会同时生效，共同过滤竞赛列表。

### ❓ 职业导航和考研支持有什么内容？

- **职业导航**：提供职业规划、就业指导、招聘信息等服务
- **考研支持**：提供考研资讯、院校信息、备考资料等支持
