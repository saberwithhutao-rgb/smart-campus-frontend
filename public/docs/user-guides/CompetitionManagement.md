## 🏆 浏览竞赛

1. 进入「竞赛管理」页面
2. 可以看到所有正在报名的竞赛列表
3. 使用筛选功能:按类别(数学建模、程序设计等)、按级别(校级、省级、国家级)
4. 点击竞赛卡片查看详情

## 📝 报名参赛

1. 在竞赛详情页查看比赛要求、时间、奖项等信息
2. 确认符合条件后,点击「立即报名」按钮
3. 填写报名表:选择参赛组别(个人/团队),如果是团队赛邀请队友加入
4. 确认信息无误后提交
5. 等待审核结果(通常会通过站内消息通知)

## 💡 参赛建议

- 提前了解比赛规则和要求
- 组队赛要找靠谱的队友,明确分工
- 注意报名截止时间,不要错过
- 参加比赛重在学习和积累经验
