## 📖 页面简介

智慧校园首页是平台的入口页面，展示平台名称「小睿」和三大核心功能模块，用户可快速跳转到所需功能。

## 🎨 视觉设计

### 主视觉区

- 动态渐变背景（蓝紫色渐变，8秒循环动画）
- 浮动几何形状装饰（三角形、正方形、圆形、长方形、菱形、六边形、星形、十字形、心形）
- 光晕效果和粒子动画
- 居中显示平台名称「小睿」

### 动画效果

| 动画     | 说明                     |
| -------- | ------------------------ |
| 渐变背景 | 背景颜色循环变化         |
| 光晕脉冲 | 光晕效果周期性放大       |
| 粒子漂浮 | 粒子在背景中缓慢移动     |
| 形状漂浮 | 几何形状上下左右浮动     |
| 标题淡入 | 页面加载时标题从下方淡入 |

## 🚀 功能模块

首页提供三大功能入口，点击卡片即可跳转：

### 1. 智能学习 📚

- **描述**：数智孪生助学
- **功能**：个性计划 + AI高效备考
- **跳转页面**：<a href="/ai/chat" target="_blank">/ai/chat</a>（智能问答AI助手）

### 2. 校园生活 🏠

- **描述**：孪生校园智管
- **功能**：行为监测健康 / 图书馆服务
- **跳转页面**：<a href="/campus/library-reservation" target="_blank">/campus/library-reservation</a>（图书馆座位预约）

### 3. 成长决策 🏆

- **描述**：数字赋能竞赛
- **功能**：信息匹配 + 科研复试
- **跳转页面**：<a href="/career/competitions" target="_blank">/career/competitions</a>（竞赛管理）

## 💡 使用方式

1. 打开智慧校园平台，进入首页
2. 浏览三大功能模块
3. 点击任一卡片，跳转到对应功能页面
4. 使用后退按钮或导航栏返回首页

## 📱 移动端适配

- 屏幕宽度 ≤ 768px 时，功能模块由三列布局变为单列
- 浮动形状透明度降低，避免遮挡文字
- 标题字体大小自适应调整

## ❓ 常见问题

### ❓ 首页的背景动画会影响性能吗？

动画使用 CSS 实现，对性能影响较小。如在老旧设备上感觉卡顿，可联系技术支持反馈。

### ❓ 点击卡片后没有反应怎么办？

请检查：

- 网络连接是否正常
- 是否已登录平台
- 浏览器控制台是否有报错

### ❓ 可以自定义首页的功能模块吗？

目前首页功能模块是固定的，不支持自定义。如有特殊需求，可向学校信息中心反馈。

### ❓ 首页的“小睿”是什么意思？

“小睿”是智慧校园平台的品牌名称，寓意聪明、智慧的校园助手。

### ❓ 如何返回首页？

点击顶部导航栏的 Logo 或「首页」链接即可返回。
