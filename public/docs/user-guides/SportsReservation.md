## 📖 页面简介

体育设施预约系统支持在线查看场馆和场地的实时状态，进行场地预约、查看场地详情、占用他人未到场场地等功能。

**开放时间：** 每天 7:00 - 23:00（节假日除外）

## 🏀 支持的场馆类型

| 图标 | 类型     | 说明           |
| ---- | -------- | -------------- |
| 🏀   | 篮球场   | 标准篮球场地   |
| 🏸   | 羽毛球场 | 标准羽毛球场地 |
| 🎾   | 网球场   | 标准网球场地   |
| 🏓   | 乒乓球场 | 乒乓球场地     |
| 🏐   | 排球场   | 标准排球场地   |

## 📝 预约流程

### 第一步：填写预约信息

1. 选择预约日期（只能选择今天及以后的日期）
2. 选择预约时间（07:00 - 22:00，每小时一个时段）
3. 选择预约时长（1-4小时，系统会根据开始时间自动限制最大时长）

### 第二步：选择场馆

1. 点击场馆按钮选择运动场地（如“篮球馆”“羽毛球馆”等）
2. 场馆按钮会显示对应的运动图标
3. 选中场馆后，下方会显示该场馆的场地分布图

### 第三步：选择场地

1. 查看场地图，了解场地状态：
   - **绿色**：可选（可预约）
   - **红色**：已预约（可占用）
2. 点击场地进行选择
3. 已选场地会显示在底部，可点击移除

### 第四步：确认预约

1. 核对预约信息（场馆、日期、时间、时长、场地）
2. 点击确认完成预约

## 🗺️ 场地图图例

| 颜色    | 状态   | 说明                     |
| ------- | ------ | ------------------------ |
| 🟢 绿色 | 可选   | 空闲场地，可直接预约     |
| 🔴 红色 | 已预约 | 已被他人预约，可尝试占用 |

> 💡 红色场地会有脉动动效和👆图标提示，表示可点击尝试占用。

## 🔘 场地详情与操作

点击任意场地会弹出详情弹窗，显示：

- 场地编号
- 所属场馆
- 当前状态（可用/已预约/已占用）
- 该场地的所有有效预约列表（预约日期、时间段、预约人）

根据情况可执行以下操作：

### 预约场地

- 点击「预约场地」按钮
- 系统会使用当前已填写的预约信息
- 确认后完成预约

### 离开场地（仅自己的预约）

- 如果该场地是你自己预约的
- 点击「离开场地」按钮释放场地

### 占用场地（他人的预约）

- 如果该场地被他人预约
- 点击「占用」按钮
- 确认后该预约会被你占用（适用于预约用户30分钟内未到的情况）

## 📋 预约规则

| 规则         | 说明                            |
| ------------ | ------------------------------- |
| 最大预约数量 | 每人同时最多可预约 **3个** 场地 |
| 单次最多选场 | 每次预约最多可选择 **2个** 场地 |
| 最大预约时长 | 单次预约最长 **4小时**          |
| 开放时间     | 每天 7:00 - 23:00               |
| 日期限制     | 只能预约今天及以后的日期        |

## 🔄 刷新状态

点击「刷新状态」按钮可以手动更新所有场地的实时数据。

## ❓ 常见问题

### ❓ 为什么有些场地显示“已预约”但还可以占用？

如果预约用户在30分钟内未到达场地就位，其他用户可以点击「占用」按钮获取该场地。这是为了提高场地利用率。

### ❓ 如何查看自己当前有哪些预约？

在场地详情弹窗的预约列表中，属于你的预约会显示“离开场地”按钮，并可查看预约信息。

### ❓ 可以取消预约吗？

可以在场地详情弹窗中点击「离开场地」来释放场地。

### ❓ 为什么有些场馆类型显示不同的图标？

系统会根据场馆类型（篮球、羽毛球、网球、乒乓球、排球）自动显示对应的运动图标。

### ❓ 最多可以选择几个场地？

单次预约最多可选择 **2个场地**，但每人同时最多持有 **3个有效预约**。

### ❓ 场地上的脉动动效是什么意思？

红色场地上的脉动动效表示该场地已被预约，但可能可以占用（用户未到场时）。
