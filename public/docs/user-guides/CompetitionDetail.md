## 📖 页面简介

竞赛详情页用于查看某个竞赛的完整信息，包括竞赛简介、时间地点、参赛要求、竞赛规则等，并提供报名入口。

## 📋 竞赛基本信息

页面顶部展示竞赛的核心信息：

| 信息     | 说明                                  |
| -------- | ------------------------------------- |
| 竞赛名称 | 竞赛的完整名称                        |
| 竞赛类型 | 程序设计 / 数学建模 / 创意设计 / 其他 |
| 竞赛级别 | 国家级 / 省级 / 校级                  |
| 竞赛状态 | 进行中 / 即将开始 / 已结束            |

### 状态标签颜色

| 状态     | 颜色    | 说明                   |
| -------- | ------- | ---------------------- |
| 进行中   | 🟢 绿色 | 正在进行的竞赛，可报名 |
| 即将开始 | 🟠 橙色 | 尚未开始的竞赛         |
| 已结束   | ⚪ 灰色 | 已结束的竞赛，不可报名 |

## 📝 竞赛详情内容

### 竞赛简介

简要介绍竞赛的背景、目的和意义。

### 竞赛信息

| 字段     | 说明                  |
| -------- | --------------------- |
| 竞赛时间 | 竞赛举办的具体时间    |
| 竞赛时长 | 竞赛持续时间          |
| 竞赛地点 | 举办地点（线上/线下） |
| 报名截止 | 报名截止日期          |
| 主办方   | 竞赛主办单位          |
| 联系方式 | 咨询电话或邮箱        |

### 竞赛标签

显示竞赛相关的标签，如“算法”“创新”“团队赛”等。

### 参赛要求

参赛者的资格要求，如专业限制、年级要求、组队要求等。

### 竞赛规则

按分类展示竞赛规则：

| 规则分类 | 说明               |
| -------- | ------------------ |
| 参赛资格 | 哪些人可以参赛     |
| 团队规则 | 组队人数、成员要求 |
| 赛程安排 | 比赛各阶段时间安排 |
| 评分标准 | 评审规则和评分细则 |
| 奖项设置 | 奖项种类和奖励     |
| 其他     | 其他补充说明       |

> 💡 **必读规则**：重要规则会标注「必读」标签，请务必仔细阅读。

## ❓ 常见问题

### ❓ 为什么点击报名后跳转到外部网站？

竞赛报名统一由各竞赛主办方管理，平台仅提供信息展示和官方链接跳转。请根据官网指引完成报名流程。

### ❓ 如何查看已报名的竞赛？

目前平台不存储用户的竞赛报名记录。如需查看，请登录各竞赛官网查询。

### ❓ 竞赛信息有误怎么办？

请联系学校信息中心反馈，或联系竞赛主办方核实信息。

### ❓ 已结束的竞赛可以查看结果吗？

部分竞赛支持查看结果，可在竞赛详情页查看相关说明，或访问竞赛官网查询。

### ❓ 规则中的“必读”标签是什么意思？

标注「必读」的规则是竞赛的重要条款，请务必仔细阅读，避免因不了解规则而影响参赛资格。
