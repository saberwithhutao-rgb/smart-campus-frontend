## 📖 页面简介

图书馆座位预约系统支持在线查看楼层、教室和座位的实时状态，进行座位预约、查看座位详情、占用空闲座位等功能。

**开放时间：** 每天 7:00 - 23:00（节假日除外）

## 📝 预约流程

### 第一步：填写预约信息

1. 选择预约日期（只能选择今天及以后的日期）
2. 选择预约时间（07:00 - 22:00，每小时一个时段）
3. 选择预约时长（1-4小时，系统会根据开始时间自动限制最大时长）

### 第二步：选择楼层和教室

1. 点击楼层按钮（如“1楼”“2楼”等）切换楼层
2. 查看教室列表，每个教室显示：
   - 教室名称
   - 状态标签（空闲/适中/紧张）
   - 总座位数、可用座位数
   - 空闲率进度条
3. 点击教室卡片进入座位选择

> 💡 **推荐教室**：系统会按空闲率排序，推荐当前最空闲的教室

### 第三步：选择座位

1. 查看座位图，了解座位布局：
   - **绿色**：可选（可预约）
   - **红色**：已预约（可占用）
   - **紫色**：讲台（不可选）
   - **橙色**：门（不可选）
   - **蓝色**：窗（不可选）
2. 点击绿色座位进行选择
3. 可以同时选择多个座位（最多5个）
4. 已选座位会显示在底部，可点击移除

### 第四步：确认预约

1. 点击「确认预约」按钮
2. 核对预约信息（教室、日期、时间、时长、座位）
3. 点击确认完成预约

## 🔘 座位详情与操作

点击任意座位会弹出详情弹窗，显示：

- 座位编号
- 教室名称
- 该座位的所有有效预约列表（预约人、预约日期、时间段）

根据情况可执行以下操作：

### 预约此座位

- 点击「预约此座位」按钮
- 系统会使用当前已填写的预约信息
- 确认后完成预约

### 离开座位（仅自己的预约）

- 如果该座位是你自己预约的
- 点击「离开座位」按钮释放座位

### 占用座位（他人的预约）

- 如果该座位被他人预约
- 点击「占用」按钮
- 确认后该预约会被你占用（适用于预约用户30分钟内未到的情况）

## 📋 预约规则

| 规则         | 说明                            |
| ------------ | ------------------------------- |
| 最大预约数量 | 每人同时最多可预约 **3个** 座位 |
| 最大预约时长 | 单次预约最长 **4小时**          |
| 开放时间     | 每天 7:00 - 23:00               |
| 日期限制     | 只能预约今天及以后的日期        |

## 🔄 刷新状态

点击「刷新状态」按钮可以手动更新所有教室的实时座位数据。

## ❓ 常见问题

### ❓ 为什么有些座位显示“已预约”但还可以占用？

如果预约用户在30分钟内未到达座位就座，其他用户可以点击「占用」按钮获取该座位。这是为了提高座位利用率。

### ❓ 如何查看自己当前有哪些预约？

目前可通过座位详情弹窗查看自己名下的预约，完整预约列表功能正在开发中。

### ❓ 可以取消预约吗？

可以在座位详情弹窗中点击「离开座位」来释放座位。

### ❓ 为什么有些教室显示“加载中...”？

可能是网络问题或数据正在加载，请稍后点击「刷新状态」重试。

### ❓ 最多可以选择几个座位？

单次预约最多可选择 **5个座位**，但每人同时最多持有 **3个有效预约**。

### ❓ 忘记选中的座位怎么办？

底部会显示「已选座位」区域，可以看到所有已选座位并点击移除。
