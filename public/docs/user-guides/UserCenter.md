## 👤 个人信息

在个人中心可以查看以下信息：

| 字段 | 说明                                     |
| ---- | ---------------------------------------- |
| 头像 | 显示当前头像，点击「更换头像」可跳转编辑 |
| 昵称 | 用户名                                   |
| 邮箱 | 注册邮箱                                 |
| 学号 | 个人学号                                 |
| 学院 | 所属学院                                 |
| 专业 | 所学专业                                 |
| 年级 | 大一/大二/大三/大四/研究生               |
| 性别 | 男/女/保密                               |
| 角色 | 学生/教师/管理员/普通用户                |

### 资料可见性

- 页面顶部会显示当前资料状态：**公开资料** 或 **私密资料**
- 公开资料时，其他页面可读取你的公开资料快照
- 私密资料时，仅本人可见，不对外公开

## 🔐 账号安全

- **注册时间**：账号创建时间
- **上次登录**：最后一次登录时间
- **账号状态**：正常 / 禁用

## ✏️ 操作按钮

- **编辑资料**：跳转到资料编辑页面，修改个人信息
- **学习统计**：跳转到校园分析页面，查看学习数据

## ❓ 常见问题

### ❓ 如何更换头像？

点击「更换头像」按钮，会跳转到编辑资料页面，在那里可以上传新头像。

### ❓ 为什么有些信息显示“未设置”？

学号、学院、专业、年级等信息是可选的，如果没有填写就会显示“未设置”。可以点击「编辑资料」进行补充。

### ❓ 公开资料和私密资料有什么区别？

- **公开资料**：其他用户可以查看你的个人资料
- **私密资料**：仅自己可见，不对外公开

可以在「设置」页面中修改此选项。
