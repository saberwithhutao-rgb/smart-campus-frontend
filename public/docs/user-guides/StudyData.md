## 📊 页面简介

学习数据分析页面用于查看你的学习计划统计数据，包括总计划数、完成率、难度分布、计划类型分布等，并支持AI生成个性化学习建议。数据可按时间范围筛选（今天/过去一周/过去一个月）。

## ⏰ 时间范围选择

页面顶部提供时间范围选择器，支持三种视图：

| 选项       | 说明                               |
| ---------- | ---------------------------------- |
| 今天       | 查看今日的学习统计数据             |
| 过去一周   | 查看最近7天的学习统计数据          |
| 过去一个月 | 查看最近30天的学习统计数据（默认） |

切换时间范围后，所有统计数据会自动更新。

## 📈 统计分析

### 核心指标

页面顶部展示以下统计指标：

| 指标         | 说明                           |
| ------------ | ------------------------------ |
| 总计划数     | 时间范围内创建的学习计划总数   |
| 已完成计划数 | 标记为“已完成”的计划数量       |
| 完成率       | 已完成计划数 / 总计划数 × 100% |
| 未完成计划数 | 尚未完成的计划数量             |
| 延期计划数   | 超过结束日期仍未完成的计划数量 |

### 难度分布环形图

展示不同难度等级（简单/中等/困难）的计划数量分布：

- **简单**：绿色显示
- **中等**：橙色显示
- **困难**：红色显示

鼠标悬停可查看具体数量和百分比，图例下方显示各难度的具体数据。

### 计划类型分布环形图

展示不同计划类型（学习计划/复习计划/项目计划）的数量分布：

- **学习计划**：蓝色显示
- **复习计划**：橙色显示
- **项目计划**：绿色显示

鼠标悬停可查看具体数量和百分比，图例下方显示各类型的具体数据。

### 各科目计划数量

按科目分类展示计划数量，例如：

- 数学：X个
- 英语：X个
- 计算机：X个
- 等

## 💡 AI 学习建议

### 生成建议

1. 点击卡片右上角的「生成建议」按钮
2. AI会根据当前时间范围内的学习数据自动分析
3. 生成个性化的学习建议列表（以时间线形式展示）

### 重新生成

如果对当前建议不满意，可以点击「重新生成」按钮获取新的建议。

### 建议内容

AI建议以时间线形式展示，每条建议包含：

- 图标标识
- 具体建议内容
- 不同类型的建议用不同颜色区分

### 生成时间

卡片右上角会显示建议的生成时间，格式为“月-日 时:分”。

> 💡 **提示**：建议会按时间范围缓存，切换时间范围后可直接查看之前生成的建议，无需重新生成。

## ❓ 常见问题

### ❓ 为什么有些数据显示为0？

可能的原因：

- 所选时间范围内没有创建任何学习计划
- 所选时间范围内没有对应难度的计划
- 所选时间范围内没有对应类型的计划

### ❓ 如何提高完成率？

- 将大目标拆解为多个小计划
- 设置合理的开始和结束日期
- 定期查看延期计划，及时调整
- 根据AI学习建议优化学习安排

### ❓ 延期计划数是什么意思？

延期计划数指**超过结束日期仍未完成**的计划数量。这可以帮助你发现哪些计划需要调整时间安排。

### ❓ AI建议多久生成一次？

建议会缓存在本地，同一时间范围只需生成一次。点击「重新生成」可以获取新的建议。

### ❓ 建议内容会保存吗？

会。每个时间范围的建议都会独立保存，切换回来后可以继续查看。

### ❓ 图表可以交互吗？

可以。鼠标悬停在环形图的扇区上会显示该项目的具体数量和百分比。
